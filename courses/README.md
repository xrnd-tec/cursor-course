# コース資料

受講者向けの学習コンテンツ。プロジェクト運用（制作タスクなど）は [`docs/`](../docs/) を参照。

| パス | 内容 |
|------|------|
| [fundamentals/](fundamentals/) | Cursor 操作の自習レッスン（0〜13） |
