## 0:20 前半① — Cursor の3つの手段（10分）

### 講師デモ

`practice/calculator.js` を開いた状態で見せる。

| 手段 | ショートカット | やること |
|------|---------------|----------|
| **Tab** | （自動） | 入力途中に続きを提案 |
| **インライン編集** | `Cmd+K` | 選択範囲だけ直す |
| **Agent パネル** | `Cmd+I` | 会話しながら複数ファイルを変える |

**デモ手順（講師）:**

1. `calculator.js` の `applyDiscount` の中にカーソルを置き、何か書きかけて **Tab** が出るのを見せる
2. `applyDiscount` 関数全体を選択 → `Cmd+K` →「コメントを日本語に直して」→ Accept
3. `Cmd+I` で Agent パネルを開き、何も送らずに画面を説明するだけ（次のステップで使う）

> 「Tab は"続き"、Cmd+K は"ここだけ"、Agent は"会話しながら"です。今日は主に Agent を使います。」

## 0:30 前半② — Ask → Agent 切替と `@`（15分）

### 講師デモ

**ステップ1: Ask モードで聞く**

1. `Cmd+I` で Agent パネルを開く
2. 入力欄で `Shift+Tab` を押して **Ask** モードに切り替える（モード名が変わることを見せる）
3. 次を送る:

```text
@practice/calculator.js このファイルの役割を3行で説明して
```

4. 「`@` でファイルを指定すると、そのファイルを読んで答えてくれる」と説明

**ステップ2: Agent モードで実装させる**

1. `Shift+Tab` で **Agent** モードに戻す
2. 次を送る:

```text
@practice/calculator.js
applyDiscount(amount, percent) を実装して。
例: applyDiscount(1000, 10) → 900
TODOコメントは残さなくてよい
```

3. 差分（diff ビュー）が出るまで待つ

> 「Ask は"調べる・確認する"、Agent は"変える"。この使い分けが最初の型です。」

### ポイント（受講者へ）

- `@` はファイルだけでなくフォルダや `@Terminals`（エラー出力）も渡せる（今日は1ファイルだけで十分）
- モードは入力欄の左側に表示されている
- 入力欄の **Auto** はモデルの自動選択。**今日はそのままで大丈夫**

## 0:45 前半③ — 差分の確認・Accept / Reject（10分）

### 講師デモ（前ステップの続き）

Agent が `applyDiscount` を書いたら:

1. **diff ビューを読む** — 緑が追加、赤が削除
2. 意図通りか1行ずつ確認する（「ここを読む習慣が大事」）
3. Accept → ファイルが変わる
4. もう一度 Ask モードで確認:

```text
@practice/calculator.js
applyDiscount(1000, 10) の期待値は何？ 今の実装で合ってる？
```

**Reject / Checkpoint の紹介（口頭のみ、デモは任意）:**

- 気に入らなければ **Reject** で元に戻せる
- 行き過ぎたら、メッセージ横の **Restore Checkpoint** でその時点まで戻せる

> 「Accept する前に必ず diff を読む。これが Cursor を安全に使う唯一のルールです。」

### ここまでの型（板書 or スライド）

```
Ask（@ファイル 質問）
  ↓ 内容を理解
Agent（@ファイル 依頼 + 完了条件）
  ↓ diff を読む
Accept or Reject
```

## 0:55 後半 — `practice/` 課題（25分）

受講者が自分でサイクルを回す時間。講師は巡回してサポート。

### 課題 A（最低ライン・全員）

`practice/cart.js` の `getSubtotal` を改善する。

Ask モードで状況を確認してから Agent で依頼すること。

```text
【Ask】
@practice/cart.js
getSubtotal の現状の問題点を1〜2個教えて。
直す前に確認したいだけ。

【Agent】
@practice/cart.js
getSubtotal を次の条件で改善して。
- price か qty が undefined / null のアイテムはスキップ
- 空カートが 0 を返す今の挙動は変えない
- 既存の関数名・引数は変えない
```

diff を確認して Accept。

### 課題 B（余裕があれば）

`practice/cart.js` にクーポン割引を追加する。

```text
【Agent】
@practice/cart.js @practice/calculator.js
cart.js に applyCoupon(code) を追加して。
- SUMMER10 のとき getSubtotal の 10% 引きを返す
- 無効なコードのとき getSubtotal をそのまま返す
- calculator.js の applyDiscount を使ってよい（前半②を見ていない／Reject した人は、未実装なので先に実装させること）
- 新規ファイルは作らない
```

### 課題 C（さらに余裕があれば）

`practice/index.js` を `node practice/index.js` で動かしてみる。  
エラーが出たら Agent に貼り付けて直してもらう（エラー対応の型を体験）。
