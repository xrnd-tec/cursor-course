## 第3章 三つの道具 — 0:20（10分）

> `Tab`、`Cmd+K`、Agent の3つを扱います。使い分けの勘どころを押さえます。

### 講師デモ

`practice/calculator.js` を開いた状態で見せます。

| 手段 | 画面からやる | Mac | Windows | やること |
|------|-------------|-----|---------|----------|
| **Tab** | （なし） | （自動） | （自動） | 入力途中に続きを提案 |
| **インライン編集** | （なし） | `Cmd+K` | `Ctrl+K` | 選択範囲だけ直す |
| **Agent** | 右上の `Agents Window` | `Cmd+I` | `Ctrl+I` | 入力欄を開く／フォーカスし、会話しながら複数ファイルを変える |

> **説明の順番**: 先に画面のどこを押すかを見せてから、ショートカットを紹介します。
> ショートカットは受講者が変更している場合があり、押しても効かないと最初でつまずいてしまいます。
> Mac の `Cmd` は、Windows では `Ctrl` に読み替えます（`Shift+Tab` は両方同じです）。

**デモ手順（講師）:**

1. `calculator.js` の `applyDiscount` の中にカーソルを置き、何か書きかけて **Tab** が出るのを見せる
2. `applyDiscount` 関数全体を選択 → `Cmd+K` →「TODOコメントだけを、処理内容が分かる具体的な日本語に直して。コードは変更しないで。」
   確定は、インラインの入力欄が **Accept** / **Reject**、行単位の差分（diff）が **Keep** / **Undo**（旧版はどちらも Accept / Reject）
3. `Cmd+I` で Agent の入力欄を開き、何も送らずに画面を説明するだけ（次のステップで使う）。
   別ウィンドウが開く版では、右上の Agent ボタンまたは `Option+Cmd+J` で右パネルを表示する

> 「`Tab` は『続き』、`Cmd+K` は『ここだけ』、Agent は『会話しながら』です。今日は主に Agent を使います。」

## 第4章 Ask と Agent — 0:30（15分）

> Ask で中身を知ってから、Agent に手を入れてもらいます。

### 講師デモ

**ステップ1: Ask モードで聞く**

1. `Cmd+I` で Agent の入力欄を開く
2. 入力欄左下のモード名をクリックして **Ask** を選ぶ（`Shift+Tab` はモードを順送りする）
3. 次を送る:

```text
@practice/calculator.js このファイルの役割を3行で説明して
```

4. 「`@` でファイルを指定すると、そのファイルを読んで答えてくれる」と説明

**ステップ2: Agent モードで実装させる**

1. モードメニュー、または `Shift+Tab` の順送りで **Agent** モードに戻す
2. 次を送る:

```text
@practice/calculator.js
applyDiscount(amount, percent) を実装して。
例: applyDiscount(1000, 10) → 900
TODOコメントは残さなくてよい
```

3. diff ビューが出るまで待つ

> 「Ask は『調べる・確認する』、Agent は『変える』。この使い分けが最初の型です。」

### ポイント（受講者へ）

- `@` はファイルだけでなくフォルダや `@Terminals`（エラー出力）も渡せる（今日は1ファイルだけで十分）
- モードは入力欄の左側に表示されている
- Cursor 3.16 のモードメニューは Agent / Plan / Debug / Multitask / Ask の5つです。今日は Ask と Agent だけ使います
- 入力欄のモデル表示（**Auto** や **High** など）は、**今日はそのままで大丈夫**

## 第5章 差分を読む — 0:45（10分）

> Keep する前に、緑と赤を1行ずつ読みます。今日の要になる章です。

### 講師デモ（前ステップの続き）

Agent が `applyDiscount` を書いたら:

1. **diff ビューを読む** — 緑が追加、赤が削除
2. 意図通りか1行ずつ確認する（「ここを読む習慣が大事」）
3. **Keep**（旧版では Accept）→ ファイルが変わる
4. もう一度 Ask モードで確認:

```text
@practice/calculator.js
applyDiscount(1000, 10) の期待値は何？ 今の実装で合ってる？
```

**Undo / Checkpoint の紹介（口頭のみ、デモは任意）:**

- 気に入らなければ **Undo**（旧版では Reject）で元に戻せる
- 変更全体は Agent パネル下部の **Review** で確認できる
- 旧版で **Restore Checkpoint** が表示される場合は、その時点まで戻せる

> 「Keep する前に必ず diff を読む。これが Cursor を安全に使う土台になります。」

### ここまでの型（板書 or スライド）

```
Ask（@ファイル 質問）
  ↓ 内容を理解
Agent（@ファイル 依頼 + 完了条件）
  ↓ diff を読む
Keep or Undo（旧版では Accept or Reject）
```

### 課題 A（最低ライン・全員） — ゴール 03：不具合を直す

`practice/cart.js` の `getSubtotal` を改善します。

Ask モードで状況を確認してから、Agent で依頼してもらいます。

```text
【Ask】
@practice/cart.js
getSubtotal の現状の問題点を1〜2個教えて。
直す前に確認したいだけ。

【Agent】
@practice/cart.js
getSubtotal を次の条件で改善して。
- price か qty が undefined / null のアイテムはスキップ
- 空カートが 0 を返す今の挙動は変えない
- 既存の関数名・引数は変えない
```

diff を確認して Keep できたら完了です。

### 課題 B（余裕があれば） — ゴール 04：新しい機能を実装する（挑戦）

`practice/cart.js` にクーポン割引を追加します。

```text

@practice/cart.js @practice/calculator.js
cart.js に applyCoupon(code) を追加して。
- SUMMER10 のとき getSubtotal の 10% 引きを返す
- 無効なコードのとき getSubtotal をそのまま返す
- calculator.js の applyDiscount を使ってよい（第4章を見ていない／Undo した人は、未実装なので先に実装させること）
- 新規ファイルは作らない
```

### 課題 C（さらに余裕があれば） — ゴール 03：エラーから直す

`practice/index.js` を `node practice/index.js` で動かしてみます。  
エラーが出たら、その出力を Agent に貼り付けて直してもらいます（エラー対応の型を体験します）。
