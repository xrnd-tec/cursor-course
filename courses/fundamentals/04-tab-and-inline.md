# 4. Tab 補完とインライン編集

## Tab（灰色の続き提案）

入力中に出てくる AI 補完です。周囲のコード・最近の編集・リンター情報を使います。

| 操作 | キー |
|------|------|
| 全部採用 | `Tab` |
| 単語ずつ採用 | `Ctrl+→`（Mac は `Cmd+→`） |
| 却下 | `Esc` か、そのまま打つ |
| 次の編集位置へジャンプ | 採用後にもう一度 `Tab`（提案があるとき） |

右下の **Tab** インジケータから一時オフ / 拡張子ごとオフもできます。

### Tab が活きるとき

- 似たパターンの繰り返し
- import や型の補完
- 「今書いてる流れ」の続き

### Tab に任せすぎないとき

- 仕様判断が必要なロジック
- セキュリティやお金の計算など、レビュー必須の箇所

## インライン編集（`Ctrl+K`）

選択範囲（またはカーソル付近）を、短い指示でその場変更します。

向き:

- この関数だけリネーム / 簡潔化
- この文言を直す
- このブロックを早見表どおりに書き換える

向かない:

- 複数ファイルにまたがる機能追加 → **Agent**
- 「そもそもどう動いている？」→ **Ask**

## 使い分け早見

```text
今打っている続きが欲しい     → Tab
この選択範囲だけ直したい     → Ctrl+K
調査したい / まだ書くな       → Ask
作って・直して・動かして     → Agent
大きいので方針から           → Plan
```

## 実習

1. `practice/greeter.js` を開き、新しい関数名だけ打つ（例: `function farewell`）
2. Tab 提案が出たら、まず `Ctrl+→`（Mac は `Cmd+→`）で一部だけ採用してみる
3. `formatName` 関数全体を選択 → `Ctrl+K`（Mac は `Cmd+K`）→ `null や undefined を渡すと文字列 "null" が返ってしまう。空文字を返すように直して`
4. 同じ変更を **Ask で手順説明 → Agent で実装** でもう一度やり、差分の出方の違いを感じる
